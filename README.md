Nama produk: SIPADEDI (Sistem Informasi Peminjaman fAsilitas DtEDI)
Deskripsi singkat: Merupakan website penyedia layanan peminjaman fasilitas akademik 
Permasalahan yang Diselesaikan: 
menyelesaikan masalah mahasiswa yang mengalami kesulitan maupun kebingungan dalam memanfaatkan 
fasilitas yang ada di lingkungan DTEDI. dengan hadirnya SIPADEDI diharapkan dapat membantu mempermudah
dalam melakukan peminjaman fasilitas di lingkungan DTEDI.
Fitur Utama:
1. Cari dan Filter Fassilitas
2. Detail Ruangan dan ketersediaan sesi
3. Kelola booking (edit atau hapus bookingan yang sudah dilakukan)
Teknologi yang digunakan:
1. HTML
2. CSS
3. PHP
4. JavaScript
Cara menjalankan project secara lokal:
1. Pastikan sudah menginstal Laragon/XAMPP dan didalamnya sudah ada phpmyadmin
2. Nyalakan Laragon/XAMPP
3. Masukkan File SIPADEDI ke dalam WWW (jika menggunakan laragon) atau htdocs (jika menggunakan XAMPP)
4. Masuk ke dalam phpmyadmin lalu import database sipadedi.sql
5. lalu masuk ke dalam website dengan cara masuk ke browser lalu ketik http://localhost/SIPADEDI/dashboard.php
link deployment: https://sipadedi.online/
penggunaan AI dalam proses pengerjaan:
Dalam proses pengembangan, AI dimanfaatkan sebagai alat bantu,
terutama untuk menerjemahkan desain antarmuka ke dalam kode (HTML dan CSS) serta membantu
menyusun beberapa bagian backend. Perancangan desain awal tetap dilakukan secara mandiri
menggunakan Figma, sehingga konsep dan tata letak aplikasi berasal dari rancangan tersebut.
